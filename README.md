# -meuperfilacademico

Explicação da Atividade – Meu perfil acadêmico
1. Como você montou a estrutura básica do arquivo index.html?
Montei o arquivo utilizando a estrutura básica do HTML, começando com <!DOCTYPE html> e depois as tags <html>, <head> e <body>. No <head> coloquei as configurações da página e o CSS, enquanto no <body> coloquei todo o conteúdo que aparece para o usuário.
2. O que você colocou dentro do <head> e qual é a função de cada elemento utilizado?
Dentro do <head> coloquei o charset UTF-8, a configuração de viewport, o <title> e a tag <style>. O charset ajuda a mostrar corretamente os caracteres, o viewport adapta a página para diferentes telas, o title define o nome da página e o style contém as regras de CSS.
3. Como você utilizou as duas <div> para separar e organizar os conteúdos da página?
Utilizei duas divs para separar as informações em partes diferentes. A primeira possui a classe perfil e apresenta informações sobre mim e meus interesses, enquanto a segunda possui a classe objetivos e apresenta o que desejo aprender em tecnologia.
4. Como você aplicou o CSS dentro da tag <style>?
Coloquei as regras de CSS dentro da tag <style> no <head>. Um exemplo é o seletor .perfil, que possui a propriedade background-color com um valor definido para alterar a cor de fundo da área do perfil.
5. Quais cores e propriedades visuais você escolheu e qual foi o resultado observado no navegador?
Utilizei diferentes cores para títulos, textos e fundos das divs. Também utilizei background-color, padding e border, deixando a página mais organizada e facilitando a visualização das duas partes do perfil.
6. Qual alteração ou correção foi necessária depois que você testou a página?
Realizei o teste abrindo o arquivo index.html no navegador e conferindo se os textos, as cores, as bordas e o espaçamento estavam aparecendo corretamente. O teste também serviu para verificar se a estrutura da página estava funcionando como esperado.
